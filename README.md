# MCGen

**用一句话，生成 Minecraft 风格的像素物品。**

剑、宝石、护甲、食物和工具——尝试不同的名称与颜色，生成属于自己的物品。

![MCGen 生成效果：18 个文本提示对应的真实模型输出](docs/images/showcase/showcase.png)

以上来自当前 best 模型，使用图中英文提示生成。原图为 16×16，展示仅做最近邻放大。

目前主要完善**文字生成物品**，参考图生成路线暂缓。项目仍在迭代，复杂描述与少见物品的效果还不稳定。
