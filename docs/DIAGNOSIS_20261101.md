# 500 步试训原因诊断（2026-11-01）

结论适用于新版 v3 的这次 500 步物品联合试训，不外推为所有旧实验的共同原因。

已确认：训练曝光不足；原文本投影前未归一化，条件特征尺度失衡、注意力过度集中；平均 flow MSE 未充分暴露高噪声阶段条件学习不足。未发现采样时间方向、缓存串样或条件梯度断路。单纯增加采样步数不能恢复本轮失败的形状。

## 1. 原训练的真实曝光

重放原始 500 步的 step-addressed sampler，总计 16,000 次抽样，目标池 6,188 个：

| 条件 | 抽样次数 | 每目标平均次数 |
|---|---:|---:|
| text | 7,172 | 1.159 |
| reference | 3,215 | 0.520 |
| joint | 4,039 | 0.653 |
| unconditional | 1,574 | 0.254 |

text 与 joint 合计，每目标平均只有 1.812 次带文字的曝光，997 个目标一次都未得到。reference 与 joint 合计，每目标约 1.172 次。冻结 Qwen 有语言表征，不等于从零初始化的图像 Transformer 已经学会将它转成像素。500 步及其早期余弦衰减只适合作为试跑，不能作为质量验收预算。

增加曝光的受控实验证明原结构有记忆这 8 个样本的能力，不能因此断言它在完整数据集上的容量或泛化已足够。

## 2. 文本特征尺度失衡：确认的实现设计遗漏

读取原检查点，使用真实 Qwen3-8B 层 9/18/27 特征：

- 8 个提示共享的首 token RMS 为 357.11，其余有效 token 通常约 2–3。
- 首 token 占每个提示有效 token 平方能量约 99.8%，池化后的提示余弦相似度因此接近 1。此处池化仅用于诊断，不是实际模型的编码方法。
- 原模型直接将原始中间层输出送入 Linear，没有 token 归一化。
- 在 t=1 的固定噪声上，各文字交叉注意力层给首 token 平均分配 13.6%–33.5% 的权重；注意力熵约 0.21–0.55。归一化干预后，首 token 权重约 1%–2.4%，熵约 1.34–1.93。
- 这不表示文字内容完全丢失，而是公共高幅值信号扭曲注意力和优化尺度，降低条件学习效率。

这是本次重构遗漏的归一化环节。对照不是只观察激活大小，而是保持数据、起始权重、噪声序列、学习率和更新数相同，直接比较生成结果。

## 3. 同预算、同目标的条件对照

选择训练集的 8 个不同物品，保留真实 caption/reference。所有实验从原 500 步检查点开始，重置相同 AdamW（lr=0.0002），每次使用全部 8 个目标，新增 600 步；每步使用新噪声和新 t。

这些是专门检查可学习性的小样本实验，取消条件 dropout，不是完整语料继续训练。使用同一种子生成 8 个目标，避免靠不同种子区分物品；生成使用 40 步 Heun、CFG=1。再对 4 个未用于优化的生成种子重复，每组 32 张图。

| 实验 | 平均黑白合成 MAE（0–255） | 正确目标匹配 | alpha IoU |
|---|---:|---:|---:|
| 原文字通路 | 14.94 | 29/32 | 0.692 |
| 只加逐 token LayerNorm | **5.90** | **32/32** | **0.915** |
| 只屏蔽共同首 token | 12.16 | 29/32 | 0.766 |
| 8 个目标使用同一句文字 | 39.73 | 4/32 | 0.176 |
| 原参考图通路 | 7.83 | 31/32 | 0.852 |

“正确目标匹配”指生成结果在模型空间与这 8 个目标做最近邻匹配，不是独立语义评审分数。单种子下原文字为 7/8、归一化为 8/8，参考图为 8/8。反例在每个种子下均输出相同结果，只能匹配一个目标，支持正确条件对区分物品的作用。

仅屏蔽首 token 的改善小于整体归一化；修正采用规范化所有 token 的尺度，不硬编码删除某个 tokenizer 位置。没有跨训练随机种子或完整语料的重复试验，不能把这里的提升比例当作最终产品提升。

## 4. 为什么平均损失下降而生成仍差

对固定 32 个验证目标，用相同噪声按 t 拆开检查。t=1 是纯噪声生成起点：

- 正确文字：flow MSE 0.4020；打乱文字：0.4106，改善约 2.1%。
- 联合条件：0.3902；打乱参考图：0.4275，说明参考图已有部分影响。
- 仅用训练目标均值构造的无条件像素先验：0.3738，在这个诊断点仍优于模型。

中低噪声下输入本身包含部分目标结构，学习去噪即可降低损失，不要求已经学会从文字或参考图决定结构。平均 MSE 也不区分前景与透明背景的任务价值。因此最终 0.29 的平均损失不能作为语义、形状或可用性合格的证据。

这是一项验证设计不足，应继续保留生成图检查，并增加固定噪声的正确/打乱条件差异、高噪声区间和前景指标；本次脚本已保存这些诊断值，尚未将额外诊断计算自动加入每次训练验证。

## 5. 已检查的替代原因

- **采样方向**：已知常量 flow 的解析 oracle，Euler/Heun 在 1/20/100 步均恢复目标，最大误差小于 6e-6。
- **采样步数/引导强度**：原检查点 text 从 20 步到 100 步的 MAE 为 51.30→50.99，reference 为 41.45→41.23；CFG 1/2/4 和 Euler/Heun 都没有恢复可靠形状。
- **Qwen 缓存或 mask 串样**：缓存与直接编码最大差值 0，倒序批次准确对齐，mask 一致。
- **条件梯度断路**：实际检查点的文字投影、参考编码器、两种交叉注意力梯度均非零。高曝光实验也证明两条通路可学习。
- **训练 bf16、推理 fp32 差异**：同输入预测差异 RMS 0.00352，预测自身 RMS 1.214，约 0.29%。不是当前大幅语义/形状失败的主要解释。
- **参考图完全错配**：选取的 8 对目标和参考图已保存并逐项目视检查，具备对应关系；这不是对全量配对数据的质量认证。

仍未排除完整数据质量、模型容量、空间条件结构和风格异质性对长期效果的影响。现有证据不支持把这些未经对照的可能性直接宣布为已找到的根因。

## 6. 已落实的修正与验证

- `ModelConfig.text_normalization` 增加 none/layernorm，历史缺省为 none，保持旧模型计算行为。
- `PixelFlow.context` 在投影前对每个 token 做无参数 LayerNorm。
- 新 `configs/v3/` 实验显式启用 layernorm；保留 `ablations/item_joint_text_raw.yaml` 作为原始对照。
- resume 比较规范化后的配置，允许历史缺省字段，仍拒绝偷偷更改归一化语义。
- 新测试验证与诊断干预完全一致、幅值控制、null 屏蔽及历史恢复兼容；完整回归 87 项通过。

旧 500 步检查点未修改。不能修改其配置就假装已经重新学会；新配置需重新训练或在明确记录的适配实验中使用。

后续顺序：以修正配置和按目标曝光规划的预算重训；在固定生成样例、高噪声条件收益和完整验证集上对照；再判断是否需要改变参考图空间注入方式或模型容量。不能只延长旧配置训练，也不能把这 8 个目标的记忆当成泛化验收。

## 复现与证据

所有脚本、固定样本、指标及诊断权重在 `outputs/diagnosis_v3_20261101/`：

- `diagnose.py prepare`：冻结编码、缓存一致性和原训练抽样重放。
- `diagnose.py probes`：噪声分桶、梯度、精度和采样参数检查。
- `diagnose.py overfit --mode text|reference|text_normalized|text_no_bos|text_constant --steps 600`：受控记忆实验。
- `repeat_seeds.py`：四个生成种子的重复评估。
- `attention_audit.py`、`check_flow_math.py`：注意力数值与解析方向检查。
- `comparison.png`：原文字／归一化文字／参考图对照。
- `overfit_curves.png`：同预算的学习曲线。
- `tests.log`：完整回归结果。

GPU 脚本使用 `PYTHONPATH=src`；`DIAG_DEVICE=cuda:1` 可选择第二张卡。诊断权重标记 diagnostic_only，不供正式 API 直接加载。
