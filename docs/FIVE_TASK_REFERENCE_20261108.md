# 五任务平衡训练：2026-11-08

目标是保留上一轮参考图配色能力，同时加强独立文生图和联合生成中的文字监督。从上一轮完整 8,000 步权重继续，优化器重置，生成器与视觉支路从第一步共同训练，编码器冻结。

沿用原生16格数据：1,064对训练配对、864个独立目标，图像、标签、划分均不变。372对高质量训练配对具有原始短标签和精标MC描述；692对旧配对只有短标签，精标分支明确回退原标签，不伪造精标。

每次抽31对数据，每对完整展开五种任务，另加入5个无条件样本：

| 任务 | 每次更新样本数 |
|---|---:|
| 原始粗标 + 参考图 | 31 |
| 精标 + 参考图 | 31 |
| 原始粗标文生图 | 31 |
| 精标文生图 | 31 |
| 纯参考图 | 31 |
| 无条件 | 5 |

粗标是原始名称/文件信息标签，不再简化为类别词。五种任务使用同一批配对，旧配对也参与文生图；来源仍为60%新批次高质量、40%已筛旧数据，再按独立目标均匀抽取参考。各任务采用独立的时间与高斯噪声，统一Flow Matching MSE。

训练新增16,000次更新，有效batch160，总计256万次样本曝光，其中纯文生图99.2万次、约为上一轮的7.2倍。主干学习率`2e-6`、视觉支路`2e-5`，预热300步，前12,000步保持学习率，最后4,000步降至30%。不设置只训练视觉支路的阶段。

21项相关测试通过，包括同一配对完整五任务、训练/留出隔离、来源配比，以及带尾部小批次的梯度累积等价检查。GPU检查确认纯文字任务能更新主干且无视觉参数梯度，五任务混合中视觉梯度有效。GPU1空闲后实测完整batch160约0.22秒/更新、峰值预留显存19.7GiB，采用完整batch；微批80可作为后续显存受限时保持有效batch不变的实现。

在0、500、1,000、2,000、4,000、8,000、12,000、16,000步进行验证。生成对照优先展示16个高质量验证目标和8个旧验证目标，另列8个训练目标；五种任务使用相同生成噪声，常见文生图单独与更早270步、上一轮8000步对照。

另外检查固定高清参考、更换同类别现有精标文本的响应。联合输出与纯参考相似本身不足以证明文字失效；文字和参考冲突时也没有配对真值，因此不将变化幅度直接当作质量分数。

按五种任务的高质量验证生图平均MAE保留`best_balanced.pt`，另外保留`best_text.pt`、`best_reference.pt`和`latest.pt`；不再只按Flow验证误差选择模型。像素对齐是诊断代理，仍需人工检查文字语义、MC风格和装饰保留。
