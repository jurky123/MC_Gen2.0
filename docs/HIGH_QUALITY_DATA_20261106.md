## 本轮训练

本轮将**模型生成网格**从 16×16 升到 32×32，以同时容纳真实32格目标和16格放大目标。这是训练设计选择，不能据此称所有 MC 目标都有原生32格细节。高清参考进入256×256视觉编码画布；MC目标直接使用包内对应MC文件，未把高清图缩成目标，1,000对目标的可见像素及alpha与原ZIP一致。

由上轮人工筛选实验的最佳图文权重初始化，仅插值固定位置编码以适配网格；原有最佳模型另存不覆盖。

为使新数据的文生图任务真正产生学习，本轮微调生成器，Qwen 文本与视觉编码器继续冻结并提前缓存。生成器学习率 1e-5，图像注意力 1e-4；不再要求训练后的无参考图输出与旧权重逐元素相同。

- 70% 图文参考、10% 纯参考、18% 精标文生图、2% 空条件 CFG 学习。
- 文生图与空条件只从新批次的训练划分抽样。
- 参考图任务先按新批次 60%、人工筛选旧批次 40% 选来源，再均匀抽目标和参考版本。
- 新批次在所有任务中的期望占比为 **68%**。文本优先采用 MC 观察/复核描述，保留短名称随机出现。
- 首轮预算约为 **每个训练目标平均 120 次抽样**，共 1,316 个训练目标；步数由 batch 实测结果确定。
- 实测 batch **64**，峰值 reserved 约 **28.39 GiB**，约 **179 张/秒**，计划 **2,468 步**。编码器缓存完成后退出，不占训练显存。
- 分别保存参考图和文生图验证最优权重，生成训练/验证对照及固定文字更换参考图的双种子样例。测试集不用于挑选模型。

运行目录：`outputs/reference_mixed_hq_20261107/`。`queue_status.json`、`cache_progress.json`、`status.json` 分别记录队列、缓存和训练进度。`training/` 保存可恢复检查点，`generation_checks/` 保存原始 32×32 RGBA 与对照图。

```bash
PYTHONPATH=src python scripts/queue_curated_mixed.py \
  --out outputs/reference_mixed_hq_20261107 --device cuda:0
```

队列等待缓存与代码检查通过，再执行真实配对学习检查、batch 探测和正式训练。中断后保留原目录与配置，重启队列即可从 `latest.pt` 恢复。

实现验证：207 项测试通过。真实配对的小样本学习检查误差由 0.2077 降到 0.1157，纯文生图任务能更新共享参数并跳过图像适配器；这些检查用权重未用于正式训练。数据抽样见运行目录的 `data_preview.png`。

训练已完成 2,468 步。随后扩大到 56 个目标、两个种子的四组网格对照，共 1,600 张输出；[分辨率诊断与结论](RESOLUTION_VALIDATION_20261107.md)。
