# 参考图适配训练

从用户选定的 **4128 步模型**出发，冻结 Qwen 和原生成器，只训练约 **4.73M 参数的残差 MLP**，将图像/图文 embedding 校准到生成器的条件空间。新增层输出初始为零；无参考图时完全绕过适配器，沿用原来的文生图和空条件路径。

本轮不改动原最佳权重，不进行整网微调。每次验证检查原生成器全部张量的 SHA256，以及固定文本生成结果是否逐元素相同；任何变化都会使任务失败。冻结机制负责保留原能力，而非依赖回放样本尽量减轻遗忘。

## 数据和训练

- 原始高清 PNG 与真实 MC 目标配对，目标来自当前清理数据；每个目标保留 FLUX、Qwen 两个来源，共 **11,432 对训练数据 / 5,716 个目标**，**1,278 对验证数据 / 639 个目标**。保持既有划分，不使用测试集；未发现参考文件哈希跨训练/验证碰撞。
- 先均匀抽目标，再抽高清变体。**50% 纯图像、50% 图像加文本**，均以对应 MC 图为生成目标。文本只采用当前清理后的文件信息标签；纯图像分支不输入文件名或描述。
- 冻结 embedding 逐张预计算，使用与交互推理一致的图像协议。纯图像和图文输入分别缓存，联合输入由 Qwen 编码。
- 原有 Flow Matching 训练目标；每步重新抽样时间和噪声。AdamW，学习率 2e-4，100 步预热后衰减。实测 64/128/256/384/512 的吞吐和显存，再确定 batch。
- 初轮目标约为每个目标 **160 次条件曝光**，同时保留至少 1,500 个优化步；具体步数按实测 batch 调整，上限 4,000 步。小样本检查的权重不进入正式训练。

## 验证与运行

除总体误差外，在低、中、高噪声上分别比较正确参考、错误参考、文字条件或空条件。图文任务的错误参考对照**保留文字不变**，避免把文字带来的收益算成参考图收益。固定训练/验证面板会保存零训练与适配后结果；最小 Flow 误差检查点仍需要看图确认，不能直接替代原文生图最佳模型。

运行目录：`outputs/reference_adapter_20261104/`。`queue_status.json` 表示所处阶段，`cache_progress.json` 表示缓存进度，`batch_budget.json` 记录实测预算，`training/validation.jsonl` 记录能力保留检查及参考图验证，`generation_checks/` 保存图片和面板。

队列按顺序运行：真实配对学习检查 → 完成缓存 → 固定文字换参考图的验证条件 → batch 探测 → 正式训练。SIGTERM 会让训练保存当前状态后退出；同配置可从 `latest.pt` 继续。

已完成的检查：188 项回归测试通过。16 个真实配对样本上使用每步新噪声训练 100 次，另一组固定噪声下误差由 **0.132 降到 0.050**，原生成器张量完全未变。这只证明适配通路可以学习，尚不是验证集泛化结果。

另已跑通真实配对上的训练、正确/错误参考验证、检查点保存与重载、公开 Runtime 推理及对照图导出；重载后无参考图的生成张量与原 4128 步模型**逐元素一致**。

正式训练已完成 **2,382 步**，实测 batch 为 **384**，条件曝光约 **160 次/目标**。验证平均误差最优为 **2,151 步**，图文分支误差最优为 **1,195 步**。各次验证中原生成器张量和固定文生图输出均保持一致。

训练结束后，固定抽取训练内、训练外各 **12 个物品**，输出位于 `outputs/reference_adapter_eval_20261104/`，`train_overview.png`、`test_overview.png` 分别展示参考图、MC 原图、纯参考图生成和图文联合生成。训练外样本来自原始测试划分，检查了图片哈希、项目、来源与训练数据的重叠；主模型在看测试结果前由验证集确定。另保留了零训练、检查点及双种子对照。

这批抽样中，常见工具和装备在训练外数据上也能形成完整物品，但仍有色偏、过饱和及少见形状误判，图文联合并非每例都更好。训练抽样中的 `molten helmet` 目标疑似图集或异常素材，需要复核；没有从展示中移除。本次为小规模分层抽样展示，不能据此推断整体准确率。

随后新增训练内、训练外各 **64 个不重复物品**，每个比较三种条件及两个种子，另为 32 个物品比较两版高清参考图，共 **896 张输出**。结果位于 `outputs/reference_adapter_expanded_20261104/`，含可筛选图库、全部拼图、文件名标签 CSV、来源与输出哈希。未见组来自 43 个训练外项目，其中 36 个文本标签也未在基础训练文本中出现。

扩大对照确认：浅色过亮、非常规形状及种子稳定性问题同时存在于训练内和训练外；更换参考图仍可能改变部件和颜色，图文联合并非普遍优于纯参考图。所有失败样本保留，未利用这些结果重新选择模型或修改采样参数；原文生图输出仍逐元素保持一致。
