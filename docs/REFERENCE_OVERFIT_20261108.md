# 16样本参考图拟合诊断（2026-11-08）

**现有Qwen高清参考特征能够支持小样本充分拟合，视觉注入通路也确实能控制设计。** 这次没有更换生成架构或高清编码器。结果只证明训练内拟合能力，不能证明对未见装饰的泛化能力。

从当前无损16格数据中固定选择16个最高质量训练目标：头盔、剑、斧/战斧、盾牌各4种设计。每类统一使用同一个类别词，不提供独有名称；生成时所有物品共用相同Gaussian噪声，避免文字或种子成为目标标识。

两组均从当前16格270步权重初始化，更新同一个生成器与视觉适配器。batch16、2000次更新；80%类别文字加参考图、20%纯参考图。学习率为生成器1e-5、适配器1e-4，50步预热后保持不变。仍使用均匀时间的Flow Matching MSE，没有新增重建或感知损失。

- **Qwen高清组：** 直接复用实际高清参考的冻结64×4096视觉特征。
- **目标像素对照：** 将16格MC目标以可逆方式装入同尺寸token，故意提供答案，仅作为训练/注入能力的上界。固定锚点确保经过LayerNorm仍不丢信息，实际还原最大误差为2.38e-7。此组不是可部署的参考生成方案，其检查点使用独立的诊断视觉身份。

## 结果

在2000步、32步Heun、CFG1下，从纯Gaussian噪声生成；下表平均两个种子的实际PNG指标：

| 输入与任务 | 预乘RGBA误差↓ | 轮廓IoU↑ | 训练目标对应 |
|---|---:|---:|---:|
| Qwen高清特征 + 类别词 | 0.00833 | 0.99909 | 两个种子均16/16 |
| Qwen高清特征，仅参考图 | 0.01303 | 0.99060 | 两个种子均16/16 |
| Qwen组，无参考图，仅类别词 | 0.13668 | 0.73296 | 两个种子均4/16 |
| 目标像素对照 + 类别词 | 0.00768 | 1.00000 | 两个种子均16/16 |

“训练目标对应”指在同类4个目标中，按实际PNG预乘RGBA距离检索最近目标；不是泛化准确率。无参考图时，同类文字与种子完全相同，输出只能是同一原型，因此最多对应其中一个设计。

Qwen组从实验前的4/16提升到250步的13/16，1000步达到16/16，并在2000步的第二种子保持对应。图文像素误差从实验前0.12835降到最终双种子平均0.00833。

同类错配参考检查中，Qwen组和目标像素组各32张错配输出，均与被换入参考对应的正常输出**逐像素一致**。在类别文字与生成噪声不变时，改变参考图确实改变了对应设计。

Qwen组在`t=0.99`的固定噪声Flow检查：匹配参考误差0.00590，同类错误参考0.37341，无参考0.23494。配合从纯噪声生成的结果，可以排除仅依靠低噪声目标泄漏造成的“拟合成功”。

CFG2仍可正确对应设计，但Qwen图文PNG误差升至约0.01971，较CFG1更大。本诊断未混入额外文本/空条件训练，不能把这个差异直接推广到正式混合任务的最佳CFG。

## 结论与边界

应优先修正大规模训练的更新预算和条件学习安排，没有证据要求立刻更换视觉编码器。之前仅270次更新的实验没有把参考支路有效学出来；本次较小batch与充足更新后，当前特征和模型能接近重现训练目标。

这不是“仅增加步数”的单变量消融：同时缩小了数据集、移除了独有文字描述、提高了纯参考任务比例，并保持学习率。因此不能断言270步是唯一原因。小样本记忆也不证明Qwen特征对未见局部装饰保留充分。

实验分别耗时约5分52秒、6分1秒。保留原模型，未继续正式全量训练。下一阶段应逐步扩大目标数量，并同时监控训练内重建、同类错配参考损失和留出设计；预算同时考虑优化次数与图片曝光。
