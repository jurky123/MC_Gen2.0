# 下一轮：2000张多类型文生图回放

五任务保证了文字得到训练，但仍允许联合生成主要依赖参考图。广域回放用于保留原文生图能力；它不能替代“同一参考、不同文字、不同正确目标”的控制监督。

## 数据

从原文生图大数据集中固定抽取 **2000个训练目标、2000条不同原文本**，不生成或改写标签。按48个文字推断的类型分层，每组41–42张；同类再覆盖不同子类和名称。装备、工具、宝石、材料、食物、植物、容器、零件、饰品等均有覆盖。这些分组仅用于抽样，不作为新的视觉标注。

先排除全部参考任务目标的像素哈希，并排除参考图留出项目的训练数据，再进行抽样。原目录的验证划分保留，训练从不抽取验证图片。历史基础模型已经见过39个参考留出目标；本轮排除重合不能撤销历史曝光，因此不能将这些目标声称为基础模型从未见过的独立测试。

本地实验目录：`outputs/reference_text_replay2000_20261108_balanced/`。

- `text_replay_selection.json`：完整2000张清单、原标签和原始像素位置。
- `data_review/selection.csv`：便于检查的文字清单。
- `data_review/preview_00.png`、`preview_01.png`：96张固定代表样本，不按视觉效果挑选。
- `text_replay.json`：数据、缓存身份和排除审计。

[随仓库保留的12张审查样本与原标签](../examples/text_replay_2000/README.md)。

已有1064个训练配对、864个目标及粗标/精标保持原样；不新增同类重建配对。

## 训练配比

每次更新保留31对各五种任务，再混入上述2000张中的样本：

| 任务 | 每次更新样本数 | 比例 |
|---|---:|---:|
| 广域纯文生图 | 144 | 45% |
| 配对目标的粗标/精标文生图 | 62 | 19.375% |
| 粗标/精标图文联合 | 62 | 19.375% |
| 纯参考图 | 31 | 9.6875% |
| 无条件：配对5 + 广域16 | 21 | 6.5625% |
| 合计 | 320 | 100% |

纯文生图合计 **64.375%**。视觉token数量及通路不变，损失按全部320个样本平均。这里增加的是文字覆盖和任务权重，不承诺联合文字优先级已经得到解决。

从用户选定的五任务健康8000步完整模型初始化，优化器重新建立。冻结时间MLP，其余共享生成参数和视觉适配器继续学习；保留持续失稳保护。先安排最多新增8000次更新，在0/500/1000/2000/4000/8000检查；并非直接续训已经崩坏的终点。广域有条件曝光平均576次/目标，需要观察过拟合，不能只看平均训练损失。

微批量由真实混合更新测速选择，梯度累积保持逻辑batch320。

本机短测通过：microbatch320约0.419秒/更新，峰值reserved显存36.84GiB；纯文字更新共享生成器且无视觉参数梯度，冻结时间MLP逐元素不变。临时测速权重已丢弃，原8000步检查点未变。2000张原生16×16图片均通过内容哈希校验，254项回归测试通过。

按用户要求已启动后台长训练，训练前完整验证通过，确认完成至少100次更新；运行约0.47秒/更新。`status.json`与`train.log`记录实时进度，三类最佳检查点独立保存。训练完成后自动比较初始化、综合最佳、最终权重的全部56个参考测试目标、32个额外验证目标与24个训练目标。新评估目录与展示目录均独立保存，不覆盖上一轮。

## 分开验收

1. **稳定性**：梯度、持续裁剪、各任务损失、时间MLP逐元素不变。
2. **纯文字能力**：保留原常见提示回归，另加固定1024张广域验证的正确/乱序/无文字Flow诊断，重点看高噪声；24张固定验证生成分三张PNG展示。文字最佳检查点同时考虑配对与广域验证。
3. **联合文字控制**：固定参考与噪声，只改明确属性。先确认无图时文字有效，再调参考强度；不能把输出发生变化直接当成修改正确。
4. **参考泛化**：保留原训练/验证/测试分组，继续检查装饰、配色和轮廓。测试集不参与选版。

训练前广域基线已执行，保存在实验目录`baseline_broad_text/`：1024张Flow诊断及24张固定生成。t=0.99时正确文字MSE为0.188，乱序文字0.536，无文字0.317，说明当前纯文字条件仍有预测收益；这不等同于具体颜色编辑已经成功。此过程没有优化器更新。

已增加可选 `--guidance-order reference_first`，计算“有参考时加文字”的差分；默认仍为原来的`text_first`。这个对照不需要训练，在两种scale相等时两条公式等价。它只能放大已有响应，不能凭空学会编辑。下一步的文字决定目标样本应作为单独实验，不在这2000张中伪造修改监督。

## 本机命令

```bash
PYTHONPATH=src python scripts/prepare_five_task_reference.py \
  --out outputs/reference_text_replay2000_20261108_balanced \
  --checkpoint outputs/reference_five_task_20261108/training/best_text.pt \
  --freeze-time-mlp --text-replay --replay-targets 2000

PYTHONPATH=src python scripts/render_text_replay_selection.py \
  --out outputs/reference_text_replay2000_20261108_balanced

PYTHONPATH=src python scripts/check_five_task_reference.py \
  --out outputs/reference_text_replay2000_20261108_balanced --device cuda:1 \
  --microbatches 40 80 160 320

# 数据和短检查已完成后，单独启动长训练：
PYTHONPATH=src python scripts/train_five_task_reference.py \
  --out outputs/reference_text_replay2000_20261108_balanced --device cuda:1
```

准备脚本只接受新目录；不覆盖已存在的实验或检查点。长训练入口要求该配置的GPU检查先通过。
