# 文件文本监督

当前路线使用文件信息抽取文本，不使用视觉模型生成的描述。生成模型从零训练，Qwen3-8B 冻结提供文本特征。

抽取保留太阳、灵魂、材料等名称；规范化驼峰和分隔符，移除明确的动画帧编号。根据已恢复的资源路径、组件标识和图层后缀隔离异常样本。没有恢复原路径的名称仍属于弱监督，不能视为核实过的游戏物品名称。

当前数据：311,510 张训练图片、40,808 张验证图片，每图一条文本；额外隔离 13,411 张训练图片。图片与原数据划分保持一致。

[查看可下载的小样本](../examples/data_review/README.md)，包含原图、处理结果、来源和已知漏收例子。可独立运行检查，不需要下载完整数据集。

实现与实验入口：

- `src/mcgen/resource_text.py`：文本抽取和隔离规则。
- `scripts/build_resource_text_training.py`：构建纯文件文本数据。
- `scripts/run_resource_text_training.py`：精确文本缓存及历史续训实验。
- `scripts/run_resource_text_scratch.py`、`scripts/queue_resource_text_scratch.py`：当前从零训练与评估。
- `scripts/compare_resource_text_interim.py`：固定提示、种子的检查点对照。

完整训练脚本依赖本地完整数据与缓存布局；模型权重、全量数据、缓存和运行输出没有上传。`grounded_labels`、视觉标注及对应队列属于已放弃路线的历史实验代码。

早期从零训练的第 2,000 步，在固定 1,024 张验证图片上误差为 0.1873；数值低于旧模型，但部分物品类别和颜色控制仍不稳定。原 README 展示图来自此前选定模型，不能代表当前随机初始化实验。
