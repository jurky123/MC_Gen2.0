# 新旧参考图方案评估结论

本轮使用64个训练内目标、64个既有训练未见目标，以及16组同文字不同目标的验证样本（32个目标）；每个使用两个种子。主对照输入、种子及32步Heun设置一致。共保存1,664张对照输出，其中768张复用已核验的旧评测输出；旧图文原始批次复现32例，31例逐像素相同，另一例最大差1个uint8级别。当前执行条件下，新版与重新载入的原文生图底座原始张量逐元素一致。

## 结果

| 64个训练未见物品，两个种子 | 旧MLP | 新空间注意力 |
|---|---:|---:|
| 图文联合：预乘RGBA平均绝对误差，越低越好 | 0.08398 | 0.07253 |
| 图文联合：目标alpha轮廓IoU，越高越好 | 79.0% | 84.1% |
| 纯参考图：预乘RGBA平均绝对误差 | 0.08790 | 0.10373 |
| 纯参考图：目标alpha轮廓IoU | 78.2% | 69.6% |

图文联合的目标误差下降13.6%，轮廓IoU增加5.1个百分点，两种种子下方向一致。训练内图文也略有改善。部分过亮样本缓解，但白色物品和特殊造型仍有错误。这些是与配对MC目标的相似度指标，不能单独衡量MC风格或装饰保留。

纯参考图在本轮明显较弱：例如训练未见redstone helmet、bottle with resin会失去原类别结构，训练内也有同类现象，不能只解释为训练外泛化问题。

同文字组中，换参考图确实会改变输出，但主要可见变化仍是配色；slime sword等样本的特殊刀刃仍被简化为常见剑形。辅助的二选一目标匹配检查中，旧图文46/64次更接近自己的目标，新图文44/64次；变化幅度增加并没有伴随这一检查的提升。这个小样本检查也会受颜色和弱标签影响，不是装饰保留率或总体准确率。

## 比较边界

旧版最佳step2151，约144.5次目标曝光，图文/纯图各50%；新版最佳与最后均为step1787，约60次曝光，图文80%/纯图20%。旧版两个任务各约72次曝光，新版图文约48次、纯图约12次。本轮是可用版本效果对比，训练预算和任务比例不同，尚未隔离架构因素。

新版最佳与最后检查点的全部模型张量相同。未改动训练、权重或公共源代码，没有根据这些结果重新选择检查点或调节采样设置。

建议继续把新版作为图文联合的候选路线，纯参考图暂时保留旧版基线。下一轮重点应是对齐任务曝光预算，并人工确认同类不同装饰的参考/目标配对，再检查局部结构是否真正得到保留；目前不宜宣布装饰多样性已经得到稳定提升。
