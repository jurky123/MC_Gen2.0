# 约 2,000 张完整物品的双文本监督扩容

本轮按用户要求扩大纯文生图实验：每张图片保留文件名抽取文本；当前视觉描述合格时，抽到图片后等概率选择两种文本。按用户后续指示，描述异常只弃用该描述，图片仍通过文件名标签训练。继续使用冻结 Qwen3-8B；高清参考图路线保持暂停。

## 数据与采样

- 原始来源为 `native16_v3` 的 MC/Mod 物品，沿用项目与内容的全局训练/验证划分，不使用 test。
- 新选择 1,800 个训练候选、192 个验证候选；15 类均衡抽样，每项目最多 8 张新候选。排除之前已经标注过的目标。
- 全部 1,992 张候选图已逐页查看，排除 141 张零件、材质层、界面素材及类别不符图片。完整但造型特殊的 Mod 物品仍保留。初始抽查与随后全图复查分别留档。
- 首次筛查后为 1,983 张生成描述；其中后来复查剔除的图片仍保留原标注作为审计记录，不进入最终训练目录。
- 保留原恢复实验的 378 张训练图片与 43 张验证图片。最终为 **2,055 张训练图片、216 张验证图片**。新候选合计排除 142 张图片（141 项全图复查排除，加首次规则筛查的 1 张 inner 素材）。
- `filename_text` 只做文件名分词与分隔符清理，不以视觉颜色替换“太阳、灵魂”等名称含义；`descriptive_text` 沿用图像加名称审核方案。原始文件名、旧描述、模型原文和质量标记保留。
- 2,046 个训练目标保留两条文本，9 个训练目标仅保留文件名；验证集另有 3 个目标仅保留文件名。`TaskSampler` 先均匀选目标再均匀选其文本。两条文本不使图片获得双倍采样权重。文本模式占 90%，双文本图片内名称/详细描述各占 50%，仅名称图片始终选择名称；另 10% 是原有无条件训练。
- 在真实构建目录上执行 100,000 次采样审计，检查目标数量、每个目标可用文本数及实际比例。实际抽到 90,161 次文本、9,839 次无条件；双文本目标内名称比例 50.057%，全部文本抽样中名称比例 50.258%（含单标签图片，理论值 50.219%）。

## 标注与审查边界

使用本地 Qwen3-VL-8B-Instruct，固定修订与已验证权重，单张中性灰背景图片加文件名，确定性解码。复用已接受的最终审核提示；不重复独立的图像观察步骤，因为该步骤的输出本来就未输入最终审核器。协议明确记录这一差别。

空描述、下划线描述、显式名称冲突、解析失败及背景污染只让详细描述失效；图片本身合格时保留文件名监督。全部 1,983 条自动输出中空描述和下划线描述均为 0。固定样本有 12 条详细描述不可靠，按用户要求仅弃用描述，不删除图片。未知名称和保留原文件名后的名称信息丢失标记本身不等于错误，仍作为弱标注记录。所有描述都不宣称经过完整人工认证。

固定 64 张候选样本在生成描述前选定，覆盖 48 张训练候选和 16 张验证候选；其中 6 张图片在标注前剔除，58 对图文完成非盲助手复查：46 条基本可信、7 条明显矛盾、5 条有不支持细节。这不是专家标注准确率。保留全部判断与理由，12 条不可靠描述回退到文件名监督。

## 固定训练和评估方案

从 `outputs/text_recovery_core_20261102/training/latest.pt` 初始化生成器，重新初始化优化器，训练 6,000 步、batch 16、学习率 5e-5、warmup 100、每 500 步保存和验证。文本编码器及模型架构不变。预计每个训练目标约 40 多次文本曝光，少于此前小核心集；本轮是扩容配方试验，不是单变量数据量消融。

原恢复实验的 171 个固定探针全部保留，包括核心验证、宽范围短名称、详细描述、训练拟合与基本颜色/类别提示。新验证候选按固定随机种子选 32 张，分别测名称和详细描述；图片被剔除时记录缺失且不补选；描述不合格时仍保留短名称评估。本次新样本有 4 张图片因完整性排除，最终评估新增 28 条短名称、28 条长描述，总计 227 个固定案例，每个训练前后各生成一次。所有比较采用相同提示、种子、32 步 Heun、CFG 2，不做强制轮廓、调色板或 alpha 后处理。

以训练前恢复版为对照，报告前景 IoU、合成 MAE、空前景，以及项目层面的配对统计；同时查看生成图。像素误差不等于语义准确率，loss 下降不等于质量通过。不自动替换默认模型。

## 完成结果

所有 6,000 步 loss 均有限。最终固定验证 flow MSE 为 0.16423，高于中途最低值；按预定方案比较第 6,000 步权重，不以最低 loss 事后替换终点。

下表为固定种子、相同采样参数下的样本均值。合成 MAE 越低越好，前景 IoU 越高越好；它们衡量与参考图片的相似性，不是提示语义准确率。

| 开发验证组 | 数量 | 合成 MAE：扩容前 → 后 | 前景 IoU：扩容前 → 后 |
|---|---:|---:|---:|
| 原核心验证 | 43 | 28.916 → 29.716 | 0.829 → 0.805 |
| 原宽范围短名称 | 64 | 42.992 → 43.256 | 0.656 → 0.640 |
| 原宽范围详细描述 | 12 | 40.235 → 34.526 | 0.677 → 0.692 |
| 新验证图片：短名称 | 28 | 31.234 → 34.722 | 0.812 → 0.800 |
| 新验证图片：详细描述 | 28 | 27.832 → 29.130 | 0.806 → 0.796 |

原训练拟合探针 16 张的 MAE 从 9.012 变为 17.515、IoU 从 0.975 变为 0.935，显示对原小核心集的记忆下降；不能将其当作验证泛化指标。所有 227 条提示在两组中均无完全空前景输出。

项目层面的配对 bootstrap 中，原详细描述组 MAE 差值为 -6.06，95% 区间 [-12.76, -0.78]（11 个项目）；新短名称组为 +3.07，区间 [1.25, 5.06]（25 个项目）。原短名称 IoU 差值区间跨 0，新详细描述 MAE 差值区间也跨 0。均为单训练种子的开发集探索性比较，不能外推为全面质量结论。

查看全部 36 个基本颜色/类别提示、12 个原详细提示和新验证组前 8 张图片的长短提示后，可以确认：部分详细提示改善，例如细剑类别、冰苹果颜色；但铜柄/钻石头等部件材质绑定仍有错误。部分短提示生成更单色，镐柄跟随主体颜色，背景有轻微杂点。HSV 目标颜色占比从 0.872 升至 0.942，并不等于颜色控制更准确，因为不该染色的部件也可能被染色。

因此本轮结论为：**双文本/文件名单标签回退机制已实现并验证，但此次扩容配方没有取得整体泛化提升。** 不替换原恢复候选 `outputs/text_recovery_core_20261102/training/latest.pt`。扩容终点保留在 `outputs/text_expansion2k_20261102/training/latest.pt`，供后续对照。

这次不能用于判断 50/50 随机文本本身好坏：初始化恢复版原本就采用随机混合，本轮同时改变了数据规模、分布、每图曝光与学习率。若继续定位，应在同一扩大目录和训练预算下对照“全部仅文件名”与“可靠描述随机混合”，而不是仅继续堆量。大部分新详细描述仍未逐条人工认证。

## 用户提出欠拟合后的补充诊断

扩容训练预算没有随数据量等比例增长：378→2,055 张（5.44 倍），4,000→6,000 步（1.5 倍），学习率 1e-4→5e-5。平均每图文本曝光从 152.38 降到 42.04；双文本图片的每个版本约 21 次。仅对齐原核心集的曝光量就需要约 21,747 步。因此不能用本轮 6,000 步结果直接判定扩大数据或双文本监督无效。

为检验训练样本本身是否已经学好，追加了独立的拟合诊断：每类选 2 张新训练图，共 30 张，且短名称在训练集中不重复；保留原 16 张训练探针与同一批 28 张新验证图；额外检查全部 9 张仅文件名训练图。共 157 条提示，使用另一个固定生成种子，在初始化恢复版、扩容最佳 flow 验证点（3,500 步）、最终点（6,000 步）分别生成，总计 471 张。

| 新训练图：短名称，30 张 | 33.151 | 23.584 | 23.337 |

查看全部 30 张新训练图的短提示结果与前 6 张长提示结果，仍能看到已经训练过的红斧在短名称下生成绿色、白靴生成青色、盾牌内部纹理失真等问题；因此不仅是未见图片难以预测。新训练样本拟合明显不充分，同时旧核心样本的拟合也退化了。

不过，“拟合不充分”还不能单独证明“只需更多步数”：优化、容量和监督噪声尚未隔离。3,500→6,000 步的这组生成误差还在略微改善，而 flow 验证 loss 回升，说明两者也不能混作同一个指标。

更合适的下一轮是固定当前目录与异常描述回退规则，对齐约 2.2 万步的总曝光预算，并相应延缓学习率衰减；同时跟踪新/旧训练拟合与冻结验证集，暂不继续扩大数据。该长程训练尚未启动。本诊断不改变之前“不替换恢复候选”的决定。
