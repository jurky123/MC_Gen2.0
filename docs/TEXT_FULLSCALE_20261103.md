# 全量文生图实验与当前候选（2026-11-03）

当前优先候选是全量训练的 **best，第 2,000 步**。使用者查看结果后认为基本可用、比此前模型好不少。这是实际使用评价，不等于全部自动指标改善，也不等于正式发布。第 6,000 步生成出现明显退化，不作为优先候选。训练已停止；本次仓库更新不启动训练、不更换服务配置、不发布权重。

## 数据与监督

清理保留原项目与内容划分，不移动验证／测试图片到训练集。通过规则筛查与训练集抽查，将疑似渲染碎片、拼装部件、界面层、类型冲突及用途未确认的不透明素材隔离；文件名、图像和排除理由可追溯。检查了 402 张分组样本及额外 48 个样本位置，并恢复确认完整的误隔离对象。不是逐图人工认证：隔离区仍可能包含合法物品，保留区仍可能残留碎片。数字、抽象名称和特殊形状不直接作为删除理由。

保留训练图的粗配比：工具／剑／弓 36,812，护甲 27,556，`gem`／`ingot` 6,149，苹果／书／盾 2,634，其余 251,770。分类基于文件名关键词；77.49% 未落入原有 15 类关键词，不代表这些图片异常。涉及 8,951 个项目，前十大项目覆盖 6.95%，前五十大覆盖 20.03%。

训练图中 10,000 张有合格自动描述：已有 2,037 张，新增采用 7,963 张；其余 314,921 张使用文件名监督。扩标使用 Qwen3-VL-8B、单图灰底和文件名提示，保留太阳／灵魂等抽象名称信息，避免凭名称虚构可见效果。描述冲突、为空或格式异常时，只弃用描述，保留合格图片及文件名。自动过滤通过不等于人工精标通过。

按图片均匀采样，有两条合格文本的图片再按 50/50 选择文本，不因双标签提高图片权重。任务比例为 90% 文本、10% 无条件，因此描述仅占文本条件样本约 **1.54%**；没有全局强制长短描述各半。验证仍保留此前的 213 张双文本图片，不对验证／测试进行此次扩标。

## 训练、停止与速度

- 模型：原生 16px pixel-space flow，width 256、depth 8、heads 8；冻结 Qwen3-8B 的 9／18／27 层，完整 128 位置 BF16 特征。参考图路线暂停。
- 从上一轮保守续训的 best 8,000 步初始化，针对新数据重建 Adam。
- 计划 200,000 步，microbatch 32、累积 2，有效 batch 64；1,000 步 warmup，学习率从 1e-5 按 cosine 降至 1e-6。
- 每 2,000 步用固定 1,024 个验证样本、固定噪声与时间步评估并保存 latest／best。
- 冻结文本特征预计算到 mmap，保持完整 padding 和 BF16 位表示，没有裁剪、量化或重新训练文本塔；共 283,614 条唯一条件文本。
- 使用者要求北京时间 11 月 3 日 09:00 停止。队列在当前操作结束后保存第 6,000 步检查点，于 09:00:34 完成退出，没有触发强制终止。训练完成量为原计划的 3%，平均约 1.064 次文本曝光／图。

短测速约 0.453 秒／更新仅适用于小型热缓存，不是全量训练实测吞吐。实际全量运行约 04:50 至 09:00，包含大缓存随机读取、验证及存盘，明显慢于该短测速。后续预算需依据全量日志重新估计，不能直接套用小缓存结果。

## 三方评估

355 组固定提示／种子包括原有 227 例和新增 128 个清理后验证集文件名。三组均使用 32 步 Heun、CFG 2；两张 GPU 生成的扩容前基线逐像素相同。没有使用锁定测试集，旧验证分组之间存在重叠，不合并成总分。

| 指标 | 扩容前 best | 全量 best 2,000 | 最后 6,000 |
|---|---:|---:|---:|
| 相同 1,024 验证样本 flow MSE ↓ | 0.22663 | 0.21905 | 0.25207 |
| 原有核心类别 43 例 composite MAE ↓ | 29.8217 | 29.7503 | 33.6914 |
| 长尾文件名 128 例 composite MAE ↓ | 45.0061 | 44.3939 | 43.8442 |
| 长尾文件名 128 例 alpha IoU ↑ | 0.6386 | 0.5856 | 0.5530 |
| 36 个颜色组合例的请求颜色像素占比 ↑ | 0.9427 | 0.9372 | 0.8758 |

长尾 MAE 变化的项目 bootstrap 区间跨越零，alpha IoU 下降区间不跨零；这些是当前开发样本上的估计，不含训练随机种子不确定性。相同文本可以对应不同合理外观，因此像素距离、目标轮廓重合度和颜色像素占比都不是完整的语义质量指标。

人工查看了 60 个三方对照案例：全部 36 个基本类别／颜色组合及前 24 个长尾案例，其中 8 个还对照目标图片。6,000 步存在轮廓破碎、零散像素及主体变淡；2,000 步大体保住原有能力，部分外观有改善。使用者的实际观感支持将 **2,000 步 best 升为当前优先候选**。后续评估应补充 MC 风格、完整性、文本符合度和多样性，而非只依靠配对像素指标。

实验入口及用途：

| 入口 | 用途 |
|---|---|
| `scripts/clean_fullscale_items.py` | 生成可追溯的清理清单、隔离理由及目录 |
| `scripts/annotate_text_expansion.py --root ...` | 使用图片及文件名补充描述，支持续跑 |
| `scripts/queue_fullscale_text.py` | 此次实验的标注、构建、缓存、训练及评估串行队列 |
| `scripts/stop_fullscale_at.py` | 根据已记录队列的进程身份定时停止，保留恢复检查点 |
| `scripts/evaluate_text_recovery.py --root ...` | 固定提示与种子的成对生成评估 |
| `scripts/compare_fullscale_stopped.py` | 此次停止点的三方对照汇总 |

日期命名的脚本是实验复现记录，部分依赖本机已有 `outputs/`、数据索引和下载核验清单，不是下载即用的公共训练服务。`mcgen` CLI 才是通用入口。停止后如需恢复，应先确认检查点与停止记录，再按新的授权处理停止标记；本次整理没有恢复任务。
