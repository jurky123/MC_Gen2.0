# 训练集与测试集标签生图展示

全部是选定的 **4128 步模型**生成的图片。左栏使用训练集标签，右栏使用原始测试集标签，各 16 张；测试图片的目标哈希、来源项目与训练集无重合，这些测试标签的完整字符串也未出现在训练标签中。

按武器、工具、装备、宝石、材料、魔法、食物和其他物品的关键词分层抽样，每层每组两条。生成前筛选可读的 2～6 词标签，要求明确的末尾物品词及已声明的颜色、材料或主题词；排除部分明显组件、技术标记、过稀疏或全不透明素材。类别只是文本关键词分组，并非人工确认的视觉类别。完整规则在 `scripts/sample_dataset_showcase.py`。

标签保持原样；统一种子 20261112、32 步 Heun、CFG 2、FP32，无按生成质量或单图种子挑选。源数据原图只在本地来源核对页展示，没有冒充生成结果，也未新增上传到此目录。已查看的测试案例不能再算作完全未查看的最终评测；本图是定性展示，不代表总体质量比例。
